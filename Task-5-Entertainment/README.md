# Growfinix Internship – Task 5

## Entertainment: Short-Form Video Marketing Strategy

### Project: BattleRush

BattleRush is a fictional mobile multiplayer action game created for this internship task.

### Objective

The main goal is to create awareness for the BattleRush launch through short-form videos on Instagram Reels and YouTube Shorts.

### Target Audience

- Age group: 16–28 years
- Mobile gaming audience
- Students and young working people
- Multiplayer and action-game players
- Regular Instagram Reels and YouTube Shorts viewers

### Content Strategy

The campaign focuses on:
- Gameplay clips
- 1v1 challenges
- Beginner vs Pro
- Funny gaming moments
- Viewer challenges
- Podcast-to-short clips

### Five Ad Videos

1. Last Second Win
2. 1v1 Challenge
3. Beginner vs Pro
4. Unexpected Fail
5. Viewer Challenge

### Tools

- VN Editor
- Pictory
- YouTube Studio Analytics

### Key Metrics

- Views
- Watch time
- Average percentage viewed
- Likes
- Comments
- Shares
- Subscriber growth

### Platforms

- Instagram Reels
-YouTube Shorts
